# Brand
Visual identity shared by every screen.

## Files
- `MacobarMark.swift`: the mark, a dot (the agent) resting on a line (the Dock). The dot bounces like a launching app while the agent works. `scale` keeps it crisp at any size; colours come from the surrounding foreground style and tint.

## Public surface
- `MacobarMark(isWorking:isActive:scale:)`

## Depends on
Nothing.
